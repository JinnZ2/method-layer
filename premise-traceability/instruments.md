## I1  RETROGRADE CITATION SEARCH

  PROBLEM IT ADDRESSES
    Imports travel downstream. Corrections appear downstream and DO NOT
    travel back. A premise crossing a field boundary arrives ungraded
    and is typically received at a higher grade than it left (the
    promotion error). Meanwhile the field that inherited it is the one
    doing the load testing.

  PROCEDURE
    1. Identify a premise and its issuing field.
    2. Identify fields that IMPORT it — search for the premise's
       consequences, not its name. It will be renamed on crossing.
    3. Search the importing field's literature for objections to the
       premise, not for uses of it.
    4. Check whether the issuing field cites those objections. Record
       the answer either way.

  WHY IT WORKS
    The objection is likelier to sit in the field that INHERITED the
    premise than in the field that issued it. The issuing field treats
    the premise as an open problem it has learned to live with; the
    inheriting field is trying to build on it and finds out where it
    fails.

  WORKED EXAMPLE
    See downstream.md D4. The arrow-of-time premise is issued by
    physics and imported by philosophy of mind and systems
    neuroscience. Two substantive objections (a reduction failure and a
    sufficiency failure) were located downstream. Whether physics cites
    them is NOT CHECKED.

  OUTPUT TYPE
    A citation-direction map, plus a null-or-hit on whether the loop
    closes. A null is a result and is recorded as one.

## I2  CHAIN GRADING
    (see GRADES.md for the legend)

  PROCEDURE
    1. Write the forced sequence: because it had to be done THIS way,
       then THIS follows, which means THIS follows.
    2. Grade EVERY link, not just the disputed ones.
    3. Mark where the chain forks and which links each branch promoted.
    4. Count [INST] links after the first. If zero, say so explicitly —
       the chain is a deduction structure, not an empirical one.

  DIAGNOSTIC THE COUNT PRODUCES
    A chain with one [INF-I] parent and no instrumented link after it
    concentrates its entire exposure in the parent. The terminal
    problems in each branch may then be one question about the parent's
    range, not several problems about the branches.

  WORKED EXAMPLE
    chain-audit-b5.md.

## OPEN — SPECCED, NOT BUILT

  - PRACTITIONER-SOURCED REGISTER. Addresses the S3 ceiling: an
    assumption nobody has noticed generates no citation, so a
    publication-sourced register scores structurally zero on invisible
    assumptions. A second register sourced from practitioner report —
    what people inside the work know is assumed but has never been
    worth writing down — would have different coverage and different
    blind spots. The two registers' disagreement is the useful output.

  - PER-CELL LINEAGE for the ADOPTED_FOR column ([obs] documented vs
    [inf] reconstructed). Required by S4 before any row is cited
    elsewhere.

  - PARTITION DECLARATION CHECK. Where a field derives a directional or
    existential claim from a coarse-graining, check whether the
    partition is declared as a variable or treated as bookkeeping. See
    the coarse-graining note in boundary-grqm.md.
