# BOUNDARY SECTION — THE GR/QM COLLISION, DECOMPOSED

CC0. Added 2026-09-08.

Design brief: mark each item by WHAT IS ACTUALLY BEING IMPORTED and
WHAT THE CONSEQUENCE OF IMPORTING IT IS, then cross-reference, so a
reader can trace one import forward through the other rows rather than
reading each in isolation.

CLAIM UNDER TEST: "general relativity and quantum mechanics are
incompatible" may not be one problem. It may be SEVEN SEPARATE IMPORTS
FAILING AT ONCE, currently reported under one name. If so, the naming
is itself a coarse-graining.

Each row: IMPORT / CONSEQUENCE / CROSS / DOWNSTREAM.

---

B1  ABSOLUTE TIME (see A1)
  IMPORT       time as an external global one-dimensional parameter
  CONSEQUENCE  assuming a universal simultaneity, and that "evolves"
               has a single meaning. Any theory where time is local and
               dynamical cannot receive the formalism unchanged.
  CROSS        A1, A2, B5
  DOWNSTREAM   Every use of the word EVOLUTION in QM presumes B1. So
               "the wavefunction evolves" is not a neutral description;
               it is a claim requiring B1 to hold.

B2  CONTINUITY / SMOOTH MANIFOLD (see A6)
  IMPORT       differentiability of spacetime at every scale
  CONSEQUENCE  assuming arbitrary precision and infinite divisibility.
               If spacetime is granular, GR's differential structure is
               an APPROXIMATION, not a description.
  CROSS        A6, A8, B4
  DOWNSTREAM   Note the asymmetry: BOTH theories inherit calculus, but
               only GR is being asked to give it up in most quantum
               gravity programmes. Nobody has run the reverse — hold
               the manifold, revise the quantum side. That arm is
               UNMEASURED, not excluded.

B3  SEPARABILITY / POINT PARTICLES (see A7)
  IMPORT       that a system can be individuated and separated from its
               surroundings, and that excitations are identifiable
               objects
  CONSEQUENCE  assuming a local energy density exists. GR has NO local
               energy density and no separability — gravitational
               energy is not localizable. So QFT's basic bookkeeping
               unit has no referent in GR.
  CROSS        A7, B6
  DOWNSTREAM   The particle ontology of the standard model rests on B3.
               If B3 fails at the boundary, the field's unknown-list
               (pre-shaped as MISSING ENTITIES — which particle, what
               mass) is shaped by an import that does not survive the
               boundary it is being used to cross.

B4  PERTURBATIVE METHOD (see A8)
  IMPORT       that prediction proceeds by expansion in a small
               coupling
  CONSEQUENCE  assuming the answer is reachable by that route. The
               statement "gravity is non-renormalizable" is a
               PERTURBATIVE statement. The field states that so few
               non-perturbative results exist that the seriousness of
               the omission cannot be estimated.
  CROSS        A8, B2
  DOWNSTREAM   If B4 is the failing import, the incompatibility is a
               property of the METHOD and not of gravity. This row can
               invalidate the framing of the whole boundary section. It
               has the highest leverage and the least attention.

B5  UNITARITY / TIME-REVERSIBILITY
  IMPORT       QM requires that the laws run backwards — information is
               never destroyed
  CONSEQUENCE  assuming reversibility as a STRUCTURAL requirement, not
               an empirical finding. GR says a black hole erases
               everything except mass, charge and momentum. So one side
               imports reversibility and the other imports an
               irreversible process.
  CROSS        A3, A4, B1
  DOWNSTREAM   Same premise, opposite direction: reversibility of the
               microscopic laws is EXACTLY what forced the arrow of
               time to be imported from entropy (A3). So reversibility
               generates a problem in thermodynamics (no arrow) and a
               different problem at the black hole boundary
               (information loss). One import, two failures, treated in
               two literatures that do not cite each other.
               STRONGEST CROSS-REFERENCE IN THE REGISTER.
               Chain audit: see chain-audit-b5.md.

B6  DEFINITENESS OF THE METRIC
  IMPORT       that spacetime has ONE definite value at each point
  CONSEQUENCE  assuming the gravitational field is classical while
               everything else is not. If a massive body can be in
               superposition, the spacetime it curves is in
               superposition — and there is a live claim that this
               violates the equivalence principle.
  CROSS        B3, B7
  DOWNSTREAM   Never stated as an assumption, because it is the DEFAULT
               that quantum mechanics already denies for every other
               field. The asymmetry is the finding: QM abandoned
               definiteness everywhere except the stage.

B7  THE EQUIVALENCE PRINCIPLE IS INSTRUMENT-RELATIVE
  IMPORT       a measurement scale, inside the statement of a
               foundational principle
  CONSEQUENCE  one formulation makes it explicitly relative to
               apparatus accuracy: for every experimental apparatus
               with some limiting accuracy, and every spacetime event,
               there EXISTS a neighbourhood small enough that the
               outcome is independent of event and velocity. So the
               principle holds locally TO WITHIN the precision of the
               device.
  CROSS        B2, B6, A5
  DOWNSTREAM   A foundational principle whose statement contains the
               measuring device. Same move as A5 (observer-independent
               entropy requiring a chosen coarse-graining) and as the
               coarse-graining note below: the instrument enters the
               physics and is then formally treated as bookkeeping.
               STRONGEST SINGLE FIND in the boundary section.

## COARSE-GRAINING AS THE SHARED MOVE

The joint between the thermodynamic and particle-physics threads. Not
yet a numbered row — pending a decision on whether it is a row or its
own thread.

  THERMODYNAMIC SIDE
    No arrow in its own mechanics, so it imports one from entropy
    increase. But entropy is defined over a coarse-graining: count the
    microstates compatible with a macrostate. WHICH macro-variables
    count is a choice (A5). So the arrow of time is a property of a
    CHOSEN PARTITION of state space.

  PARTICLE PHYSICS SIDE
    What counts as a collision EVENT is also a chosen partition —
    trigger criteria first (discarding the overwhelming majority of
    events in real time, permanently, by pre-set rules), then
    reconstruction deciding which detector responses group into one
    object.

  THE JOINT
    Entropy's ARROW and the event's EXISTENCE both rest on an
    unexamined partition. In both fields the partition is formally
    treated as bookkeeping while doing ontological work.

  CONSEQUENCE FOR THE FIELD'S OWN UNKNOWN-LIST
    The unknowns are pre-shaped as ENTITIES — which particle, what
    mass. But what an entity IS was fixed by the partition. So the
    unknown-list cannot serve as the pre-scope inventory; it is what
    you get AFTER the scope was declared.
